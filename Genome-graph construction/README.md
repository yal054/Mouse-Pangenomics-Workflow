- `minigraph-cactus-graph-construction.sh`: run the MGI minigraph-cactus pangenome pipeline using Cromwell
  - pipeline WDL is available [here](https://github.com/twlab/cig-pipelines/blob/main/wdl/pipelines/pangenome/mcgb.wdl)
  - key workflow files include:
    - `$GRAPH.inputs.json`, specifying workflow parameters such as file name prefixes, reference assemblies, and resource limits/requests
    - `$GRAPH.seqfile.tsv`, listing all assemblies to be used in a given graph
- `panacus.sh`: used to calculate graph statistics
  - docker image: `mgibio/panacus:0.2.4`
